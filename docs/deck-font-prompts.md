# Deck 图标字体与世界提示

Linux 构建在私有资产阶段从受检 1.4.3 RomFS 生成四个区域字体补丁。只接受精确 SHA-256 的 External.bfotf，交换其 X/Y 轮廓和水平度量，重新计算字体校验和。A/B 保留菜单字母，不作全局字体交换。每份归档仅替换这一个等长成员，其他成员、归档偏移与解压长度不变，无需扩大字体 ResourceSizeTable 条目。

`data/deck-ui/fonts.bin` 记录四个固定路径的原文件和补丁长度、摘要；`recipe.json` 记录转换器摘要。包清单覆盖全部补丁文件。运行时只允许这四个路径，核对实际原文件和补丁摘要，拒绝链接、管道、截断或错误版本。原始 RomFS 不改写。补丁压缩后的长度可以不同，文件读取使用补丁自身的偏移和长度。`TOTK_STEAMDECK_UI=0` 同时停用原创 Deck 图示和这些字体补丁。

世界 HUD 的六个受检 R8 提示由原创蒙版生成，按菜单/世界上下文使用不同 A/B 标签。字体 X/Y 转换、R8 HUD、整机图分别处理，不能把其中一项当作全部提示已经一致。混合展示世界操作和菜单操作的帮助页、字体形式的世界 A/B 提示，以及烘焙教程图仍须逐场景实机核对。

回归覆盖自造字体与归档的边界、成员保留、校验和、真实 Linux 文件描述符、不同文件长度、偏移、错误源、链接/管道和 500 次打开关闭无泄漏。私有输入的实际 FreeType 比较与最终游戏截图保存在部署验收报告中，不随公开源码分发。
