# Deck 图标字体与世界提示

Linux 私有资产阶段仅接受固定 1.4.3 字体、Common 与 ResourceSizeTable 输入，生成六项只读覆盖：四区域字体、Common 布局和资源分配表。原始 RomFS、着色器与纹理缓存不改写。

External 图标字体交换 X/Y，保留菜单 A 确认、B 取消；四个肩键字形替换为原创 L1/R1/L2/R2 标牌。另建独立 DeckWrld 字体交换 A/B 和 X/Y；仅世界 CtrlGuide、操作说明及附加目标选择的固定五个布局引用它。两种字体共享相同的肩键提示并各自保留原字符度量，避免菜单开关影响同屏世界操作说明。Common 的三个普通字母同步调整；帮助页十组引线按原创 Deck 图的坐标求解，验证三种模式与骑乘状态的标记中心和文字端点。实际游戏仍是最终验收依据。

肩键转换在 CFF 末尾新增 CharStrings INDEX，只以等长操作数更新 Top DICT 的指针，既有 Private、charset、子程序及其他地址保持原位。未修改字形的程序逐字节保留；所有横向度量不改。SFNT 重新计算表偏移、长度及全字体校验和，BFOTF 与 SARC 同步记录实际长度，其他成员内容不变。不支持的指针宽度、字体版本和度量直接拒绝。

新增字体和动画增加了归档解压长度。配套分配表仅扩大原有五项资源记录，不新增或修改其他记录；CRC 冲突、未知版本、溢出及缺项均拒绝。压缩后文件长度和摘要分别记录，读取采用实际替代文件的长度。

`data/deck-ui/fonts.bin` 使用 NDUIF002，固定六项原文件/替代文件长度与 SHA-256；`recipe.json` 的 `deck-world-menu-shoulders-v3` 记录所有转换器摘要。运行时核对完整包清单和实际打开的原文件及替代文件，拒绝符号链接、管道、截断和摘要不符。`TOTK_STEAMDECK_UI=0` 同时停用这些覆盖和原创机身图。

公开回归使用自造字体、归档和资源表。旧 v2 的菜单及世界变体各有 546 次 FreeType 位图与度量比较；v3 的新增肩键必须另作实际渲染和游戏画面验收，不能沿用旧结果。原始游戏资源和实际截图不随源码分发。内存写读、完整指引动画与实体按键/触屏/陀螺仪方向等验收分别记录，不互相代替。
