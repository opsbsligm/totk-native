# 验证范围

更新：2026-11-05。此记录限定本独立工程的源码构建，不替代玩家实机验收。

从空目录生成 1435 个游戏 C 文件，完整生成记录包含 282702 个函数。已完成完整原生代码编译、最终链接，并编译验证目录容量修复。全部 28667 个着色器完成导出、转换与打包；BC7 转换验证了一个最大容器，尚未完成全部纹理转换。

完整资源阶段还需要六个系统共享字体和全部纹理转换。 因此尚未验证 `--stage all` 成功生成完整新运行包。只有持有健康、对应版本的完整转储并通过所有阶段，才有可运行个人包。

CI 编译不含游戏数据的公共运行时，并从实际编译命令生成 C/C++ 分析输入。分析器必须成功处理全部编译单元；分析失败或缺少覆盖汇总会使 job 失败。SAST、依赖、密钥、工具链容器扫描保持启用，扫描完成不表示零告警，审查处置以对应 MR 为准。工具链及下载归档摘要记录在 `.gitlab/toolchain.env`。

两款游戏默认设置 60 帧上限；解除原 30 帧限制、软件时钟验证不代表设备稳定 60 帧。实体按键、六轴方向、存档实机兼容、休眠恢复和运行性能由玩家验收；`hardware_validated=false`。

Linux NVN 的逐帧 GPU 完成时间接口尚未实现，使用接口约定的 `-1` 表示不可用；不把缺失数据计作 0 毫秒或纳入 GPU 分位数。Vulkan 后端已有的已完成提交计时汇总仍独立保留，它与逐帧 GPU 完成时间、屏幕呈现间隔是不同指标。

仅允许分享源码导出包。生成的游戏代码、游戏资源、系统字体、个人运行包和存档不属于公共构建产物。

## 输入链路审计补充

`TOTK_INPUT_AUDIT` 默认关闭。显式启用后，SDL 事件进入侧栏捕获之前会记录键盘、焦点、原生手指和鼠标事件，保留原键盘及焦点日志格式。手指记录含阶段、窗口、设备、接触标识和标准化坐标；鼠标记录含来源和窗口坐标，便于区分原生触摸与兼容鼠标事件。不会记录文字输入内容。

每个进程最多记录 512 个受支持的事件，另有启用与预算耗尽标记。旧版本只记录键盘及焦点，缺少手指日志不能证明触摸未送达；新版本也必须先确认审计已启用、预算未耗尽，并结合实际展开/收起画面判断。虚拟输入成功写入内核、指针事件模拟、显示器合成画面和掌机物理触屏分别验收；输入日志不替代实体按键、菜单确认取消或陀螺仪方向验收。

CI 测试编译实际生产审计函数，以合成事件验证默认静默、键盘/焦点格式、手指生命周期、鼠标来源、文字排除和事件上限；该测试不声称覆盖合成器路由或物理触屏。
