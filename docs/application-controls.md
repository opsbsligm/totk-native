# 掌机控制栏与输入

点击角落的调节角标先展开快捷面板，再点击功能卡片、面板空白处或“展开完整设置”进入完整菜单。完整菜单可返回快捷面板，点击“收起”恢复角标。角标与面板短条均可拖动，松开后吸附到最近的边或角；也可选择八个停靠位置。菜单采用物理 Deck A 确认、B 取消；世界玩法保持原绑定。应用面板展开时捕获输入，收起时清除残留按下状态。游戏菜单范围与验证边界见 [菜单输入](menu-confirm.md)。

原生触摸与 Gamescope 的普通鼠标回退共用一个界面指针：角标内部起手的拖动在移出原边界后仍由应用处理，世界起手划过角标不会被截走。另一输入源或无关鼠标移除不会取消当前拖动；所属设备移除、失焦及队列溢出会释放归属和残留按下状态。收起角标的拖动期间同样捕获游戏输入，并屏蔽尚未松开的手柄按钮。此归属回归与完整新包实机验证分开记录。

侧栏与下拉选项使用不透明深色背景；颜色和间距仅在绘制侧栏期间生效，退出后恢复原样式。角标自带柔和投影，雪原与天空等高亮画面上仍读得清；图标是三轨滑块的调节符号，不依赖任何字形。

完整菜单的列表在空白处直接上下拖动，滚动条关闭，改由列表右缘的细指示条显示位置：拖动时点亮，离开后淡出，页面无可滚动内容时不出现。列表下方不再有滚动按钮。

取消拖动会清除待处理的旧指针按下，同时保留其他输入来源的松开事件；设备复位后，新手势在复位之后重新起手。

快捷面板和完整设置都可按 B 取消并收起；收起的角标仍由触屏展开。

控制栏可以调整 30/40/45/60/90/120 帧上限、输出窗口尺寸、原生传感器运动开关和重新居中。改帧率保持已验证的实时游戏时钟；帧上限不代表设备能稳定达到该帧率。输出尺寸是呈现窗口大小，不冒充内部渲染分辨率。

各画面选项的后端能力、回退和验证范围见 [扩展功能](feature5.md)。不支持的选项明确显示不可用；窗口缩放和重复帧不冒充内部渲染分辨率或帧生成。SteamOS 全屏尺寸仍由 Gamescope 管理。设置原子保存到 XDG 配置目录的 `totk-native/control.ini`；读取时拒绝链接、管道、公开权限、超长文件和非法数值，异常配置回退默认值。

运动输入优先读取物理 Deck HID 的 IMU，经融合后提交游戏六轴接口，完全不读取 Steam Input 的鼠标/摇杆陀螺仪映射。Steam Input 继续提供普通按键。启动器只借用传感器模式位，退出时按所有权检查恢复原值。外接有真实 IMU 的手柄可以走 SDL 传感器接口。方向、校准和瞄准效果仍需实机验收。

## 金手指导入

控制栏支持版本绑定的数据补丁开关；当前不内置未经验证的无限体力/无敌地址。`NATIVE_CHEATS_FILE` 可指向 owner-only（0600）的文本文件，缺省在用户游戏数据目录读取 `native-cheats.txt`。格式：

```text
NATIVE_CHEATS_V1 totk-1.4.3 EXACT_64_CHARACTER_NSO_BUILD_ID
# Name module-relative-offset expected-u32 replacement-u32 (all numbers hex)
```

只能使用与当前 build ID 一致、由自己验证的主模块可写数据地址，最多32条，32位对齐；禁止覆盖代码、宿主内存、重复地址或执行脚本。选择开关只排队，在游戏呈现线程检查原值并执行 compare-and-swap；关闭时仅当数据仍为本补丁写入值才恢复，冲突则报错并保留现值。它是可逆的数据补丁导入器，不解释 Atmosphère 指令，也不对任意游戏版本套地址。

上段描述的是独立数据补丁导入器。Atmosphère VM 导入与预设、完整 Build ID 绑定和执行状态见 [扩展功能](feature5.md) 与 [金手指预设](cheat-presets.md)。软件构建、模拟内存补丁回归与真实游戏行为分开验证；目前 `hardware_validated=false`。

触屏侧栏分为画面、控制、Amiibo、金手指四页；当前能力与执行状态见 [扩展功能](feature5.md)。快捷键不再打开侧栏。

世界提示使用独立 DeckWrld 图标字体，菜单保留 External 字体；两者各自按实际物理按键显示。构建仅接受受支持的 1.4.3 输入，生成四区域字体、Common 布局及配套资源分配表的六项只读覆盖。原始 RomFS 保持不变。系统帮助的十组指引按现有三种模式及骑乘状态求解，保留原文字端点；最终效果仍须以当前候选的实际游戏验收为准。

## 原生相机视野

画面页增加触摸视野滑杆（70%–150%），默认 100% 保持原始视野。
比例也作用于弓箭和瞄准镜缩放；过大的角度、非有限数和零值保持原值。
偏好文件追加可选的 `fov` 字段，旧配置继承 100%，原有键位和其他默认值不变。

生产 AOT 在 1.4.3 main 模块的两处相机加载后调用线程安全的主机接口。
接入前检查 build ID、原始指令、下一条乘法和各自周边 64 字节的 SHA-256；
代码 Mod 不能覆盖这些上下文。只有完整生成两处调用后，生成表才导出能力标记。
没有标记的运行库禁用滑杆；更改比例后，界面区分等待相机更新与后端已应用。
后端读回表示角度计算已执行，画面构图、过场和实际游玩仍须真机验收。
